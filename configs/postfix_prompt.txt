# Output Format

Respond ONLY with valid JSONL (one JSON object per paper, one object per line). Do not add prose, headings, markdown fences, or a surrounding JSON array.

Each object must contain exactly these keys:

- "ARXIVID": string
- "RELEVANCE": boolean
- "RELEVANCE_SCORE": integer from 0 to 10
- "NOVELTY_SCORE": integer from 0 to 10
- "COMMENT": string
- "AFFILIATIONS": string

Use the paper's title and abstract only. Do not infer capabilities, experiments, or novelty that are not stated. Institution prestige, author reputation, model size, dataset size, and claims such as “first” or “state of the art” are not by themselves reasons for a high score.

# Decision Procedure

Evaluate each paper independently; do not select it merely because it is the best paper in the current batch. Start with `RELEVANCE=false` and change it to `true` only after the paper clears every selection gate below. It is valid—and preferred—to select no papers from a batch.

## 1. Core selection gates

For `RELEVANCE=true`, the title or abstract must clearly establish ALL of these facts:

1. The main contribution is a learned generative visual dynamics/world model.
2. The model generates viewable future frames or video, even if generation occurs through decoded tokens or latents.
3. Future visual observations are explicitly conditioned on agent/environment actions, or on learned latent actions intended for interactive control.
4. The method supports sequential action-conditioned rollout, interactive simulation, or closed-loop prediction.
5. The paper contributes a substantive new modeling or training method, rather than only a dataset, benchmark, evaluation, application, scaling exercise, or demo.

If any fact is missing or ambiguous, keep `RELEVANCE=false`. Do not treat text prompts, action-class labels, camera paths, robot-policy outputs, or generic trajectory conditioning as agent/environment action control unless the abstract explicitly makes that connection.

## 2. Relevance score: topic fit only

Score how directly the paper addresses the target task. Do not include general paper quality or novelty in this score.

- 0: Unrelated.
- 1: Accidental word overlap only.
- 2: Mentions video, actions, or world models in an unrelated task.
- 3: Broadly adjacent, such as generic video generation, robotics, model-based RL, or visual prediction.
- 4: A visual generator/world model is central, but explicit action-conditioned future generation is absent.
- 5: Meaningful partial match, but one of visual generation, action conditioning, or interactive rollout is missing.
- 6: Close to the target, but a core gate is ambiguous, secondary, or only weakly demonstrated.
- 7: Exact target task with a concrete contribution, but narrow, incremental, application-led, or insufficiently compelling for the short daily list.
- 8: Strong direct match; all five gates are explicit and the target task is the paper's primary contribution.
- 9: Exceptional fit; in addition to satisfying score 8, the method substantially advances a central limitation such as action fidelity, long-horizon stability, generalization, or real-time closed-loop generation.
- 10: Near-perfect, field-defining fit with unusually broad importance. This should be almost never used from an abstract alone.

Relevance hard caps:

- No explicit agent/environment action input: at most 4.
- Does not generate viewable future observations: at most 4.
- No sequential, interactive, or closed-loop rollout: at most 6.
- Video generation/world modeling is only an auxiliary component or downstream application: at most 6.
- Survey, benchmark, dataset, evaluation, or demo without a new core model: at most 5.

## 3. Novelty score: technical originality only

Judge novelty independently from topic fit. A perfect topic match can still have low novelty. Begin from 3, then move upward only for concrete technical evidence stated in the abstract.

- 0-2: No original technical method; survey, replication, analysis, evaluation, or dataset/benchmark-only work.
- 3: Routine engineering or application of an existing method.
- 4: Straightforward domain transfer, scaling, fine-tuning, or recombination of standard components.
- 5: A meaningful but incremental modification with limited technical depth.
- 6: One clearly described, nontrivial technical idea, but the advance is localized or evidence is limited.
- 7: A genuinely new central mechanism, objective, architecture, or training strategy with credible evidence that it solves a target-specific problem.
- 8: High originality supported by strong evidence: multiple substantive innovations or one clear conceptual leap with convincing comparisons/ablations.
- 9: Direction-setting contribution that introduces a new formulation or capability and demonstrates broad, decisive gains. Extremely rare.
- 10: Transformative, paradigm-changing contribution. Do not assign 10 based only on promotional abstract claims.

Novelty hard caps:

- Main contribution is more/larger data, a larger model, faster engineering, open sourcing, or a new benchmark: at most 4.
- Fine-tunes or adapts an existing video generator to a new domain/action interface without a clearly new method: at most 5.
- Describes only a combination of known components, without explaining a new mechanism or objective: at most 5.
- Claims a new module/loss but gives no clear reason or evidence that it changes the target capability: at most 6.
- Abstract is too vague to identify the technical innovation: at most 6.
- “First,” “SOTA,” visual quality, parameter count, data scale, and institution prestige add zero novelty points by themselves.

## 4. Final selection rule

Set `RELEVANCE=true` if and only if:

- every core selection gate is explicitly satisfied,
- `RELEVANCE_SCORE >= 8`, and
- `NOVELTY_SCORE >= 7`.

Otherwise set `RELEVANCE=false`. When uncertain between two scores, always use the lower score. Most candidate papers should score below the selection thresholds; scores of 9 should be rare, and scores of 10 should be virtually absent.

For a selected paper, `COMMENT` must be one concise sentence naming both the action-conditioned visual-generation contribution and the concrete technical innovation. For a rejected paper, set `COMMENT` to an empty string.

For `AFFILIATIONS`, extract or cautiously infer the main institutions from the supplied metadata; if unavailable, use "Unknown Institution". Affiliations must not affect either score.
